# Plan A Errata — Repo-local Marketplace Path

This note corrects the `source.path` examples in `2026-09-03-v0.2-plugin-marketplace.md`.

## Correct contract

For a repository marketplace stored at:

```text
<repo-root>/.agents/plugins/marketplace.json
```

Codex resolves a local plugin `source.path` relative to the **marketplace repository root**, not relative to the nested `.agents/plugins` directory.

Therefore, when the plugin root is the repository root itself, the correct entry is:

```json
{
  "source": {
    "source": "local",
    "path": "."
  }
}
```

Any earlier Plan A example using `"../.."` is superseded by this erratum.

## Evidence

The correction is based on the first-party OpenAI Codex marketplace resolver tests in `codex-rs/core-plugins/src/marketplace_tests.rs`, which place a marketplace under `<repo-root>/.agents/plugins/marketplace.json`, use a local source such as `./plugin-1`, and assert resolution to `<repo-root>/plugin-1`.

The repository contract was changed to expect `"."`, intentionally failed RED against the old marketplace entry, and then returned GREEN after the production marketplace was corrected.
