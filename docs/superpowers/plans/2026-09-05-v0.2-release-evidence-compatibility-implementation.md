# v0.2 Release Evidence and Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the implemented v0.2 feature branch into an evidence-bound release-candidate surface with explicit compatibility results for Codex CLI 0.147.0 and Codex Desktop bundled runtime 0.152.0, deterministic release contracts, evidence-linked public documentation, and a verifiable RC gate.

**Architecture:** Plan F is staged evidence-first. Machine-readable release contracts define claim and compatibility state; a conservative acceptance helper prepares disposable plugin variants and summarizes bounded hook evidence; real baseline campaigns record 0.147.0 and 0.152.0 outcomes; matrices and public docs consume only those recorded outcomes. Ordinary CI validates schemas, helpers, docs, and Plan D/E regressions without launching authenticated Codex or Desktop acceptance.

**Tech Stack:** Python 3.11 standard library, JSON, Markdown, GitHub Actions, PowerShell operator commands, existing Codex plugin/marketplace/hook acceptance helpers.

**Spec:** `docs/superpowers/specs/2026-09-05-v0.2-release-evidence-compatibility-design.md`

## Global Constraints

- Work only on `feat/codex-native-plugin-v0.2`; do not merge or write to `main` during Plan F.
- Declared runtime baselines remain Codex CLI `0.147.0` and Codex Desktop bundled runtime `0.152.0`.
- Current official OpenAI documentation is platform-contract evidence, not proof that either declared baseline implements identical behavior.
- RISK-001 explicit manifest `hooks` testing uses a disposable plugin copy. The primary `.codex-plugin/plugin.json` continues to omit `hooks` unless both declared baselines have reproducible PASS evidence and a separate release decision changes the shipped manifest.
- RISK-002 remains per capability and per runtime. Never transfer a PASS from one baseline to the other.
- Preserve the Codex CLI 0.147.0 SessionEnd timeout discrepancy unless new reproducible evidence changes only its classification.
- Preserve the Desktop 0.152.0 parent-wait observation as unclassified unless a targeted acceptance run produces evidence strong enough to reclassify it.

- Do not promote `production-grade`, blanket `secure`, feature-parity, or unqualified `cross-platform` wording.
- Runtime acceptance captures exclude tokens, private transcripts, raw session identifiers, user-local credentials, and machine-local paths. Commit only bounded sanitized evidence plus hashes where the existing evidence policy calls for them.
- Python 3.11 is the repository development baseline. Hook/runtime-dependent user features continue to require Python availability as documented by release evidence.
- Every implementation task follows RED -> verify RED -> minimal GREEN -> focused regression -> narrow commit.
- Before Plan F closure, run fresh CI on the exact closure head and audit the complete Plan F delta for secrets, machine-local paths, unsupported claims, stale current-release v0.1 wording, and accidental runtime-specific assumptions.

```python
from __future__ import annotations

import argparse
from pathlib import Path

from .model import load_claims, load_compatibility, validate_release_data


def main() -> int:
    parser = argparse.ArgumentParser()
    sub = parser.add_subparsers(dest="command", required=True)
    validate = sub.add_parser("validate")
    validate.add_argument("--claims", required=True)
    validate.add_argument("--compatibility", required=True)
    args = parser.parse_args()

    claims = load_claims(Path(args.claims))
    compatibility = load_compatibility(Path(args.compatibility))
    errors = validate_release_data(claims, compatibility)
    if errors:
        for error in errors:
            print(f"FAIL: {error}")
        return 1
    print(f"PASS: {len(claims)} claims and {len(compatibility)} compatibility surfaces validated")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
