# CEK 1.1.0-beta.1 release notes

[v1.1.0-beta.1](https://github.com/aydemir0/codex-engineering-kit/releases/tag/v1.1.0-beta.1) is published as a GitHub pre-release. Its
annotated tag points to `e4d9430f23af6a248ee322559c5c5a391f3e3339`.

## Changes from the v1.0 line

- Candidate-bound verification covers relevant final working files, staged and
  unstaged changes and nonignored untracked inputs. Stale or missing evidence is
  rejected without staging the user's index.
- Local workflow recovery validates checkpoints and terminal state and avoids
  replaying coordinator side effects. Synthetic interruption/timeout tests do
  not prove arbitrary external transactions or historical campaign recovery.
- Native diagnostics distinguish discovery/host/tool, permission/CLM, malformed
  response, timeout and artifact failures, with fail-closed operator guidance.
- Managed lifecycle preflight now rejects source/profile directory overlap before
  native marketplace/profile commands or managed writes. A beta quickstart trial exposed recursive
  local-plugin cache copying; both failed disposable states were preserved.
  Runtime, profile and task paths in the corrected recipe stay outside the source.
- Public onboarding now requires the complete digest-verified official Codex CLI
  0.155.1 Windows x64 package. The quickstart distinguishes installation, host
  probing, deterministic testing and real model execution.

The product changes reached main through PR #3 and PR #4. The beta builds on:
`e5dc24941f9f3b858f1534d8404598579c5d8564`.

All 12 jobs in the [post-merge CI run](https://github.com/aydemir0/codex-engineering-kit/actions/runs/42282203433)

total, with 372 passed and 4 skipped.

## Known limitations

- A fresh CODEX_HOME inherited 143 user-global `.agents/skills` and five system
  entries in addition to CEK's eight. Descriptions were shortened to fit the
  context budget. The extra user-global skills are not assumed to be account-sync
  plugins; their actual source roots were recorded. Explicit project skill-scope
  control is the highest-impact observed usability gap. No primary account,
  global skills or account plugins were modified.
- Native Windows x64 is the verified configuration. Three-OS repository CI is
  deterministic evidence, not native runtime support on Linux/macOS/Desktop.
- Code Mode is marked under development by the pinned CLI. Model-list refresh
  timed out during startup, although the actual task completed.
- Unelevated Windows sandbox was requested; OS token level was not independently
  attested. Artifact/index/sentinel checks are not a machine-wide write audit.
- Build/typecheck/lint were skipped for this tiny fixture. Other tasks, agent
  roles, authenticated hook/compaction acceptance, model interruption recovery,
  general reliability and token/cost/latency advantages remain unestablished.

## Historical benchmark boundary

The historical experimental M4 evidence/freeze remains archived and unchanged.
Its signed completion receipt is absent; no authoritative CEK-vs-ECC result or
superiority is claimed here. This beta does not close or waive an M4 gate, rerun
its attempts or include its production authority infrastructure. The old v1.0
45-run A/B/C context evidence is a different dataset and retains its own scope.
